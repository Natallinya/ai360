## Epic A — Поиск товаров

| ID | User Story | Статус | Где в коде / комментарий |
|----|------------|--------|--------------------------|
| US-A1 | Как пользователь, хочу ввести текстовый запрос, чтобы увидеть релевантные товары | ✅ | `home` + `search-results`, `SearchApiService` |
| US-A2 | Хочу видеть, с какой площадки каждый результат | ✅ | `source` на карточке, `sourceLabel` pipe |
| US-A3 | Хочу видеть цену, фото, название, ссылку | ✅ | `ProductCardComponent` |
| US-A4 | Хочу фильтровать/сортировать (цена, площадка) | 🟡 | Сортировка по цене на BFF; UI-фильтров нет |
| US-A5 | Хочу видеть результаты по мере загрузки (streaming) | 🟡 | Есть loader; нет пошаговой подгрузки по источникам |
| US-A6 | Хочу листать результаты страницами (не больше N карточек на страницу) | ✅ | Пагинация 10 товаров, `?page=` в URL, `wbPage` на BFF |
| US-A7 | Хочу видеть только товары с рабочими фото (без «дыр» в сетке) | ✅ | `filterOffersWithWorkingImages`, догрузка WB-страниц |
| US-A8 | Хочу понятное сообщение, если поиск не удался (BFF спит, таймаут, сеть) | ✅ | `formatHttpError`, прогрев BFF, тексты на `search-results` |
| US-A9 | Хочу видеть статус каждого источника поиска (ok / error / count) | ✅ | Блок `sources` на странице результатов |

## Epic B — Вишлист

| ID | User Story | Статус | Где в коде / комментарий |
|----|------------|--------|--------------------------|
| US-B1 | Хочу добавить товар из выдачи в вишлист | ✅ | `WishlistService.add`, кнопка на карточке |
| US-B2 | Хочу видеть список на отдельной странице | ✅ | `/wishlist` |

| US-B6 | Хочу, чтобы битые картинки не засоряли список | ✅ | Prune при открытии вишлиста + `onImageError` |
| US-B7 | Хочу добавить в вишлист гибрида животных как особую позицию | ✅ | `animal-fusion.page` → `source: 'fusion'` |
