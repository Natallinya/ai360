ai360 — пэт-проект: агрегатор вишлиста, BFF, вайбкодинг с Cursor

Репозиторий: github.com/Natallinya/ai360 · Июнь 2026

Идея продукта

Пользователь ищет товар текстом или вставляет ссылку с маркетплейса, видит варианты с разных площадок в едином формате и сохраняет понравившееся в личный вишлист. Покупка — только по внешней ссылке. Бонус-фича: «гибриды животных» (генерация имени и картинки через AI).

Стек — что и зачем

СлойТехнологииПочему выбрали
Frontend Angular 21, standalone, zoneless, signals, PrimeNG, SCSS Целевой стек для обучения и публикации на GitHub. Signals + standalone — современный Angular без NgModule. PrimeNG даёт готовые карточки, кнопки, формы. Zoneless снижает лишние циклы CD.
BFF Node.js 22, Express, TypeScript, cheerio, Playwright Фронтендеру знаком TypeScript и npm. BFF прячет ключи API, CORS, SSRF-валидацию и парсинг. Playwright — единственный реалистичный путь к карточкам WB/Ozon/Allegro без публичного API.
Монорепо npm workspaces, concurrently Один npm run dev из корня вместо двух терминалов. Общий lockfile и overrides для Angular — защита от дублей @angular/core (NG0203).
CI/CD GitHub Actions, GitHub Pages, Render Blueprint Бесплатно для пэт-проекта: статика на Pages, BFF на Render free tier. CI на каждый push — сборка + 25 unit-тестов.
AI (runtime) Stable Horde, OpenAI DALL·E 2 (опц.) Гибриды животных без своего GPU. Horde — бесплатная очередь; DALL·E — fallback при наличии ключа на Render.
AI (разработка) Cursor Agent, MCP-серверы Агент пишет код по rules, проверяет BFF через MCP, открывает UI в browser MCP. Не заменяет runtime — ускоряет разработку.
Тесты Vitest (Angular 21), Playwright (PDF) Встроенный test runner Angular 21. 10 spec-файлов: сервисы, utils, компоненты.

Что сознательно не выбрали

  • NestJS / FastAPI — избыточно для тонкого BFF с 5 эндпоинтами
  • Отдельный Python-scraper — отложен; Playwright в Node покрывает импорт по URL
  • Ozon/WB поиск через API — нет легального публичного каталога; только WB search API + mock + DummyJSON
  • Auth/БД на старте — вишлист в localStorage до MVP; облако — фаза 2

Потоки данных

  1. Поиск: форма → GET /api/search?q= → параллельные адаптеры → сортировка по цене → карточки 3×3
  2. Вишлист: ProductCard → WishlistService → localStorage (без BFF)
  3. По ссылке: URL → POST /api/offers/from-url → Playwright или cheerio → предпросмотр → вишлист
  4. Гибриды: POST /api/animal-fusion → имя + генерация 384px → кэш на диске BFF
  5. WB-картинки: GET /api/wb-image/:nmId — прокси редиректов CDN Wildberries

BFF (Backend-for-Frontend)

BFF — единая точка входа для Angular. Фронт никогда не хранит API-ключи и не ходит напрямую на маркетплейсы (CORS, антибот).

МетодПутьНазначение

Плагинные адаптеры поиска

idИсточникОсобенности

Адаптеры реализуют SearchAdapter; search.service.ts вызывает их через Promise.allSettled с таймаутом — падение одного источника не ломает ответ.

Парсинг по URL

  • cheerio + fetch — Open Graph / meta для простых сайтов (books.toscrape.com)
  • Playwright (headless Chromium) — WB, Allegro, Яндекс.Маркет: антибот требует браузер
  • url-safety.ts — блокировка localhost, private IP, file:// (SSRF)

CI/CD — процессы

Два независимых контура: CI проверяет код, CD выкладывает web на Pages и api на Render.

Workflow CI (.github/workflows/ci.yml)

Триггер: push и PR в main / development.

1Checkout + Node.js 22 + кэш npm
2npm ci — установка workspaces (api, web, mcp)
3Linux fix: @rollup/rollup-linux-x64-gnu (lockfile с Windows)
4npm run build -w api — компиляция TypeScript BFF
5npm run build -w web — production-сборка Angular
6npm run test -w web -- --watch=false — 25 unit-тестов Vitest

Workflow Deploy (.github/workflows/deploy.yml)

Триггер: push в main / development. Concurrency: один деплой Pages.

1Сборка api (smoke) + scripts/write-web-env.mjs — подстановка API_BASE_URL (дефолт Render)
2ng build --configuration=github-pages — base href /ai360/
3prepare-github-pages.mjs — артефакт для Pages
4deploy-pages@v4 → natallinya.github.io/ai360

Render Blueprint (render.yaml)

  • Ветка development, регион Frankfurt, plan free
  • Build: npm ci && npm run build -w api
  • Start: npm run start -w api
  • Health: /api/health
  • Секреты (опц.): OPENAI_API_KEY, STABLE_HORDE_API_KEY

Ограничения и уроки

  • Ozon/Allegro каталог — нет легального API; честная альтернатива: WB + mock + URL
  • Render free — cold start, Playwright на проде слабый
  • Дубли @angular/core в monorepo → NG0203; лечится overrides + hoisted install
  • PrimeTemplate обязателен для pTemplate header/footer в PrimeNG

Вывод

За несколько сессий вайбкодинга: продуктовая спека, Angular 21, Express BFF, 5 экранов, деплой, MCP, 26/35 stories. Роль разработчика смещается к архитектуре и ревью; агент закрывает scaffold, интеграции и документацию — под контролем rules.
