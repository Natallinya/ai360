## 2026-06-01 — Бэкенд и парсеры (вопрос на обучении)

### Идеи для слайда «архитектура»

- Три слоя: **Angular → Node BFF → (будущий) Python scraper**
- MCP ≠ парсер: **MCP для разработки в Cursor**, scraper для runtime
- Ozon: Seller API ≠ каталог; `fetch` в Node ≠ браузер

### Тезис для доклада

> «Я фронтендер, бэкенд на TypeScript поняла за вечер. Парсер Ozon — отдельный микросервис на Python, потому что маркетплейс блокирует простой HTTP.»

### См. [BACKEND_PARSERS_AND_MCP.md](./BACKEND_PARSERS_AND_MCP.md)
